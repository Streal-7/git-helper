# Шпаргалка по Git

## 1. Описание

Git — система контроля версий. Инструмент, который помогает отслеживать изменения в файлах проекта и хранить историю изменений. При необходимости можно вернуться к более ранней версии.

## 2. Интерфейс

- Консольный (Windows, Linux, macOS)
- Оконный (Windows, Linux, macOS)

## 3. Что нужно знать для работы в консоли

### Перемещение по каталогам

- `pwd` — узнать, в каком каталоге мы находимся
- `ls` — посмотреть список файлов в текущем каталоге
- `ls -a` — список файлов, включая скрытые
- `cd ~` — перейти в домашний каталог
- `cd Catalog` — перейти в каталог с названием Catalog
- `cd ..` — перейти в каталог на уровень выше

### Создание, перемещение и удаление файлов и каталогов

- `touch file.txt` — создать файл
- `mkdir folder` — создать папку
- `rm file.txt` — удалить файл
- `rmdir folder` — удалить пустую папку
- `rm -r folder` — удалить папку со всем содержимым
- `mv file.txt folder` — переместить: сначала что перемещаем, затем куда
- `cp file.txt folder` — копировать, параметры указываются так же, как у `mv`
- `cat file.txt` — вывести содержимое файла

### Полезное

- `команда1 && команда2` — выполнить вторую команду, только если первая прошла успешно
- **Tab** — дописать имя файла или папки
- **↑ / ↓** — листать историю команд

## 4. Работа с Git

### Установка и настройка

Скачать и установить Git, затем указать имя и почту — они будут подписью под каждым коммитом.

- `git config --global user.name "Имя или ник"` — имя для всех репозиториев на компьютере
- `git config --global user.email "Адрес электронной почты"` — почта для всех репозиториев
- `git config user.email "Адрес"` — без `--global`: только для текущего репозитория (выполнять внутри папки проекта). Удобно, если для разных проектов нужны разные аккаунты
- `git config user.email` — посмотреть, какая почта действует сейчас

### Создание репозитория и первый коммит

- `git init` — создать репозиторий в текущей папке (появится скрытая папка `.git`)
- `git status` — показать состояние файлов: какие изменены, какие добавлены к коммиту, какие Git ещё не отслеживает
- `git add file.txt` — добавить файл к следующему коммиту (в индекс)
- `git add .` — добавить все изменённые и новые файлы текущей папки
- `git commit -m "Сообщение"` — сохранить снимок добавленных файлов с описанием изменений
- `git log` — история коммитов

## 5. Начало работы с GitHub

GitHub — сайт для хранения Git-репозиториев. Локальный репозиторий на компьютере связывается с удалённым на GitHub, и изменения отправляются туда.

### Отправить проект на GitHub

1. Создать на GitHub новый пустой репозиторий (без README, если проект уже есть на компьютере).
2. Связать локальный репозиторий с удалённым и отправить коммиты:

- `git remote add origin URL` — добавить удалённый репозиторий под именем `origin`
- `git remote -v` — проверить, куда смотрит `origin`
- `git branch -M main` — назвать основную ветку `main`
- `git push -u origin main` — отправить ветку `main` на GitHub; `-u` запоминает связь, дальше достаточно `git push`
- `git push` — отправить новые коммиты

При первом `push` Git попросит войти в аккаунт GitHub. Данные входа Windows сохраняет в «Диспетчере учётных данных».

### Получить проект с GitHub

- `git clone URL` — скачать репозиторий целиком на компьютер

### Fork — копия чужого репозитория

Fork (англ. «развилка») — копия чужого репозитория в вашем аккаунте GitHub. В оригинал нельзя отправлять изменения без прав, а в свой форк — можно.

1. Открыть чужой репозиторий на GitHub и нажать **Fork** — копия появится в вашем аккаунте.
2. Скачать **свой форк** (не оригинал): `git clone https://github.com/ВАШ_НИК/репозиторий.git`
3. Работать как обычно: `git add` → `git commit` → `git push` — изменения попадают в форк.
### Если на компьютере два аккаунта GitHub

Ошибка `403` при `push` значит, что Git вошёл не под тем аккаунтом. Помогает имя пользователя в адресе репозитория — тогда для него хранится отдельный вход:

```
git remote set-url origin https://ИМЯ@github.com/ИМЯ/репозиторий.git
```

### Типичный порядок работы

```
git status
git add .
git commit -m "Что изменилось"
git push
```
